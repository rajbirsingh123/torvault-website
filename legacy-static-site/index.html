FAQ

Frequently asked questions.

UL (Underwriters Laboratories) independently tests safes against real tools — prybars, drills, saws — for a set net working time. A TL‑15 safe resists a professional attack with common tools for 15 minutes; TL‑30 for 30. It’s the same standard insurers use to set coverage limits.
